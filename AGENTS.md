# Working on Aevum

Read `JOURNAL_PROJET.md` before starting work. It is the user's persistent project journal.
After every implementation change, even a small one, append what changed, what was verified, known limits and the next action. Keep its current-state section accurate. Do not claim planned or untested work is complete.
Use one `codex/` branch per evolution. Preserve saved campaign replays by versioning rule changes. Never include API keys in commits, logs, client bundles or campaign exports.
